# Rustlings

My progress learning Rust with [Rustlings](https://github.com/rust-lang/rustlings), the official set of small exercises that teach the language by fixing broken code.

## Structure

- `exercises/`: the exercises, with my fixes applied
- `solutions/`: official reference solutions that ship with Rustlings
- `.rustlings-state.txt`: Rustlings' own progress tracker

## Run it

1. Install Rust: https://rustup.rs
2. Install Rustlings:

```bash
   cargo install rustlings
```

3. Clone this repo and start the exercise watcher from inside it:

```bash
   git clone https://github.com/amiraliverse/rustlings.git
   cd rustlings
   rustlings
```

## Why

I'm learning Rust alongside data engineering. Rustlings builds the fundamentals: ownership, borrowing, structs, enums, error handling, traits.
